Iroh Link Gateway

Installs for your account and runs the gateway at login on localhost port 45475. No administrator access is needed.

Links to blake3.net and pkarr.net also need the iroh link browser extension. For Chrome or Brave, install it from the Chrome Web Store. The Firefox version is awaiting review; until then you can load it as a temporary add-on. Browser profiles are not modified.

If another application already uses port 45475, stop it before continuing.
